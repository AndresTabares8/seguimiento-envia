SEGUIMIENTO ENVÍA, 20 GUÍAS

La consulta usa el secreto GUIAS_JSON del repositorio AndresTabares8/seguimiento-envia.
El programa exige 20 guías distintas como texto. Conserva sus ceros iniciales.
Las referencias G01 a G19 conservan su orden. La guía añadida queda como G20.
El Excel conserva la fila repetida original. La lectura elimina esa repetición.

El rastreador comprueba el número en su campo propio y el primer evento de la línea de tiempo.
Exige título y descripción compatibles y fechas en orden descendente.
Si falta evidencia, muestra Sin verificar. No deduce entrega desde eventos anteriores.
Si Envía responde 401, 403 o 429, suspende las consultas restantes de ese lote.

El workflow solicita un lote a los minutos 07 y 37 de cada hora UTC, que también son 07 y 37 en Colombia.
El PC puede estar apagado. GitHub ejecuta las consultas.
GitHub puede retrasar o descartar ejecuciones en periodos de carga.
En repositorios públicos el horario se desactiva tras 60 días sin actividad del repositorio.
Revisa Actions si la página avisa que los datos tienen más de 75 minutos.

Página: https://andrestabares8.github.io/seguimiento-envia/
En Safari, Compartir, Agregar a inicio crea un acceso directo en tu iPhone.
Actualizar vista recarga el reporte, no inicia una consulta al transportador.

No subas el Excel, la imagen de la guía, guias.json ni respuestas completas al repositorio público.
Los números se guardan en el secreto GUIAS_JSON. La página publica referencias, estados y fechas.
No publica números de guía, nombres, direcciones ni enlaces individuales.
Pages tiene acceso público en esta configuración.

Para renovar el secreto desde tu Excel, ejecuta localmente:
python -m pip install -r requirements.txt
python preparar_secreto.py "ruta/a/guias.xlsx"
Copia el contenido de guias.json a Settings, Secrets and variables, Actions, GUIAS_JSON.
No subas guias.json al repositorio.

PUBLICAR_PAGES debe tener valor true en Settings, Secrets and variables, Actions, Variables.
En Settings, Pages, Source debe estar seleccionado GitHub Actions.
Para probar, abre Actions, Seguimiento Envía, Run workflow.
Comprueba el resultado de consultar y publicar. Abre la página y comprueba la fecha y G20.
Un lote con Sin verificar termina con fallo, pero publica el reporte si llegó a generarlo.

Con 20 guías y 48 lotes diarios hay 960 consultas diarias, 28800 en 30 días, antes de reintentos.
No se verificó una cuota pública de Envía para esta frecuencia. Confírmala con el transportador.
Los ejecutores estándar de repositorios públicos y GitHub Pages tienen uso gratuito según GitHub.
Repositorios privados y almacenamiento de artefactos tienen cuotas según el plan.
La plantilla retiene reportes dos días y el artefacto de Pages un día.
